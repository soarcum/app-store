# /create-app 工作流

> [!IMPORTANT]
> **边界性限制（核心要求）**：
> 本工作流的最终产物仅是一个**带有自定义名称和图标的空白应用**。
> **严禁编写任何具体的业务逻辑代码！严禁修改模板中的任何 UI 或业务逻辑！** 

## 📋 执行步骤

1. **询问意图**：用户需要告诉你他们想要做一个什么样的应用，如果没有提供，请主动询问。
2. **创建空白应用**：根据 `templates\blank-app` 模板在 `C:\Users\Administrator\Desktop\cool` 文件夹下创建一个空白应用。
3. **定制名称与图标**：
   - 创造一个优雅、简短、好记的应用名称。
   - 使用 AI 生成精美的应用图标，覆盖模板的默认图标。
4. **托管与打包**：
   - 使用 `github` MCP 创建对应的远程库，上传初始化后的代码。
   - 进行第一次编译打包为 APK 文件。如果遇到编译错误，必须修复以确保打包成功，生成可下载的 `.apk` 文件。
5. **注册与规划书**：
   - 将应用信息写入 `data\apps.json` 中。
   - **在项目根目录下创建一个 `todo.md`**，用中文列出该应用未来拟实现的基本功能。**除此之外，绝对不要编写任何具体的 Kotlin 业务代码！**
